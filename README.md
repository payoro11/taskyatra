# TaskYatra Website

Professional marketing website for TaskYatra — India's #1 Business Automation Platform.

Built with React + Vite + TypeScript + Tailwind CSS.

## Pages
- Home
- Features
- Pricing
- Contact
- Terms & Conditions
- Privacy Policy

## Tech Stack
- React 18 + Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Wouter (routing)
- shadcn/ui components

## Run
```bash
npm install
npm run dev
```
